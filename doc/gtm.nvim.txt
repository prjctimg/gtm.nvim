1. SETUP						*gtm.nvim-setup*

gtm.nvim is three things: playback control, a statusline, and reactive theming
driven by the album art gtmd already extracted. It opens no windows of its own.

Requires Neovim 0.11+ and a running `gtmd` (https://github.com/prjctimg/gtm).

lazy.nvim: >
  { "prjctimg/gtm.nvim", opts = {} }
<
Manual: >
  require("gtm").setup({ statusline_format = "compact" })
<
There are no dependencies, optional or otherwise. `setup()` is idempotent: it
can be called repeatedly (config reload, or alongside a plugin manager) without
duplicating sockets, event handlers or commands.

2. COMMANDS					*gtm.nvim-commands*

Playback:~
  :Gtm play              Toggle play/pause.
  :Gtm next              Skip to next track.
  :Gtm prev              Skip to previous track.
  :Gtm stop              Stop playback.
  :Gtm volup             Increase volume by 5%.
  :Gtm voldown           Decrease volume by 5%.
  :Gtm mute              Toggle mute.
  :Gtm seek {secs}       Seek to position in seconds.
  :Gtm shuffle           Toggle shuffle.
  :Gtm repeat {mode}     Set repeat mode: off|one|all.

Status:~
  :Gtm status            Notify what is playing right now.

Reactive theming: >
  :Gtm theme             Print the active palette as hex values.
  :Gtm theme reset       Clear the tint and restore the previous colors.
<
Connection:~
  :Gtm disconnect        Drop both sockets and stop reconnecting.

Default keymaps, all remappable through `opts.keymaps`: >
  <Leader>gp             Play / pause
  <Leader>gn             Next track
  <Leader>gN             Previous track
  <Leader>g>             Volume up
  <Leader>g<             Volume down
  <Leader>gS             Stop
<

3. STATUSLINE					*gtm.nvim-statusline*

lualine: >
  require("lualine").setup({
    sections = { lualine_x = { require("gtm").lualine_component() } },
  })
<
Anything else: >
  vim.o.statusline = "%{%v:lua.require'gtm'.statusline()%}"
<
`opts.statusline_format` picks the rendering: >
  "compact"   artist - title ▶ vol:80% ━━━━━━━━━━━━━━━━━━━━
  "detailed"  ▶ Artist - Title (Album) [01:23/04:56] vol:80% [R] [S]
<
The component hides itself while the daemon is unreachable. The position clock
advances locally between daemon events, so the progress bar never waits on the
socket.

4. REACTIVE THEMING					*gtm.nvim-theme*

With `opts.theme.reactive = true` the editor takes on the colours of the album
currently playing. gtmd extracts the palette from the cover art and broadcasts
it; this plugin never decodes an image.

  - The tint is kept while playback is paused and dropped only when playback
    stops or the track ends.
  - Semantic groups (Error, Warning, Diff, Spell, Todo, diagnostics, gitSigns)
    keep their colorscheme colours.
  - Changing colorscheme mid-track re-picks light or dark and re-tints rather
    than losing the palette.
  - A track with no cover art never tints.
  - `:Gtm theme reset` restores every group to exactly its prior value.

Add your own groups to the tint with `opts.theme.extra_groups`.

Colour ownership ~
A gtmd new enough to send resolved role sets computes the whole ramp itself and
pushes it as `bg0`, `fg`, `accent`, and the rest. The plugin only maps roles onto
highlight groups, so it performs no colour arithmetic and stays consistent with
the gtm TUI and any other client.

Against an older gtmd the plugin falls back to deriving the same roles locally
from the three palette colours. `:checkhealth gtm` reports which path is live
and the role-set version when the daemon resolved them.

5. LUA API						*gtm.nvim-api*

Playback~
  require("gtm").play_pause()      Toggle play/pause.
  require("gtm").next()            Next track.
  require("gtm").prev()            Previous track.
  require("gtm").stop()            Stop.
  require("gtm").mute()            Toggle mute.
  require("gtm").shuffle()         Toggle shuffle.
  require("gtm").cycle_repeat(m)   Set repeat: "off"|"one"|"all".
  require("gtm").seek(secs)        Seek to a position in seconds.
  require("gtm").set_volume(d)     Nudge the volume by a delta.

Statusline~
  require("gtm").statusline()        Render using the configured format.
  require("gtm").lualine_component()  lualine component table.

Theming~
  require("gtm").reset_theme()     Clear the reactive tint.

Note: `repeat` is a Lua keyword, so the public entry point is
`cycle_repeat()`, not `repeat()`.

==============================================================================
6. CONFIGURATION					*gtm.nvim-config*

Defaults: >
  {
    socket_path = nil,       -- default: auto-resolved like gtmd does
    statusline_format = "compact",
    resync_interval = 30000, -- ms between get_status_lite resyncs
    theme = {
      reactive = false,
      extra_groups = {},
    },
    keymaps = {
      play_pause = "<leader>gp",
      next = "<leader>gn",
      prev = "<leader>gN",
      volume_up = "<leader>g>",
      volume_down = "<leader>g<",
      stop = "<leader>gS",
    },
  }
<
`socket_path` overrides the socket search order, which otherwise matches
gtmd's own: `$XDG_RUNTIME_DIR/gtm/gtmd.sock`, `/tmp/gtm-$USER/gtm/gtmd.sock`,
`$TMPDIR/gtm/gtmd.sock`, then `~/.gtm/gtm/gtmd.sock`. The plugin does not start
the daemon for you.

==============================================================================
7. HEALTH						*gtm.nvim-health*

>
  :checkhealth gtm
<
Reports the Neovim version, whether `gtmd` is on `$PATH`, both socket paths and
whether they are connected, the age of the last pulse heartbeat and of the last
status snapshot, and whether a palette has arrived. Start here when nothing is
happening.
