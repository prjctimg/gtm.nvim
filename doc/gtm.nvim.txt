1. SETUP						*gtm.nvim-setup*

gtm.nvim is four things: playback control, a statusline, native pickers over the
queue and library, and reactive theming driven by the album art gtmd already
extracted. It opens no windows of its own; every picker is `vim.ui.select`.

Requires Neovim 0.11+ and a running `gtmd` (https://github.com/prjctimg/gtm).

lazy.nvim: >
  { "prjctimg/gtm.nvim", opts = {} }
<
Manual: >
  require("gtm").setup({})
<
There are no dependencies, optional or otherwise. `setup()` is idempotent: it
can be called repeatedly (config reload, or alongside a plugin manager) without
duplicating sockets, event handlers or commands.

No keymaps are set by default. Bind the ones you want: >
  require("gtm").setup({
    keymaps = {
      play_pause = "<leader>gp",
      next = "<leader>gn",
      prev = "<leader>gN",
      volume_up = "<leader>g>",
      volume_down = "<leader>g<",
      stop = "<leader>gS",
      queue = "<leader>gq",
      spotify = "<leader>gs",
      radio = "<leader>gr",
      search = "<leader>g/",
    },
  })
<

2. STATUSLINE					*gtm.nvim-statusline*

The statusline is a list of items you turn on. Only the source marker and the
state icon are on by default; everything else is opt-in. >
  statusline = {
    source = true,    -- ♫ Spotify ◉ radio ☁ podcast ❋ chart ▤
    state = true,     -- ▶ ⏸ ⏹
    artist = false,
    title = false,
    album = false,
    progress = false, -- ━━━━━ 20 columns
    time = false,     -- [01:23/04:56]
    volume = false,   -- vol:80%
    repeat = false,   -- [R]
    shuffle = false,  -- [S]
  },
<
Items render in the order above. One with nothing to show is skipped, so the
empty state is just `⏹` rather than a row of zeroes.

Source icons ~
`statusline.source` shows a marker for where the audio came from, using Nerd
Font codepoints from Material Design Icons: >
  spotify = md-spotify      U+F04C7
  radio   = md-radio        U+F0439
  podcast = md-podcast      U+F0994
  local   = md-folder_music U+F1359
  chart   = md-chart_line   U+F012A
<
A source your gtmd does not name renders nothing rather than guessing.

Those are private-use codepoints: without a patched font they show as empty
boxes. Paste the plain-Unicode set into `statusline.icons` to replace them — it
needs no patched font: >
  icons = {
    spotify = "◉", radio = "☁", podcast = "❋",
    local = "♫", chart = "▤",
  },
<
Override only the ones you like; the rest keep their defaults.

lualine: >
  require("lualine").setup({
    sections = { lualine_x = { require("gtm").lualine_component() } },
  })
<
Any statusline: >
  vim.o.statusline = "%{%v:lua.require'gtm'.statusline()%}"
<
The component hides itself while the daemon is unreachable. The position clock
advances locally between daemon events, so the progress bar never waits on the
socket.

`statusline.source` renders nothing until gtmd reports a playback source; see
PLAYBACK_SOURCE.md in the gtm repo.

3. BROWSING					*gtm.nvim-browsing*

Every picker is a `vim.ui.select` menu. The plugin draws no window and keeps no
list: your selector supplies the UI and its search. The stock fallback is a
numbered inputlist, so it works but is not searchable. Selecting a track plays
it; there is nothing to open or close.

Queue: ~
  :Gtm queue             Browse the queue; selecting a row plays it.
  :Gtm queue remove      Remove the selected row.
  :Gtm queue clear       Clear the queue after a confirmation.

`play` handles local paths, `spotify:` URIs and `radio://` streams alike, so a
queue row plays whichever kind it is. Queue edits are explicit subcommands, so
selecting a row never changes the queue.

Spotify: ~
  :Gtm spotify {query}   Search Spotify; only real tracks are listed.
  :Gtm spotify           Prompt for the query first.
  :Gtm spotify-playlists Synced playlists -> tracks.

Radio: ~
  :Gtm radio             Top Radio Browser stations.
  :Gtm radio {query}     Search Radio Browser stations.
  :Gtm radio tags        Tag -> stations.
  :Gtm radio countries   Country -> stations.

Local library: ~
  :Gtm search [query]    Search the library index.
  :Gtm playlists         Playlists -> tracks.
  :Gtm favourites        Favourites.

Cover art is not rendered in a menu. A Spotify result passes its image URL to
the daemon, so the queued row still gets art. The Lua API mirrors each picker:
`queue()`, `spotify()`, `spotify_playlists()`, `radio()`, `search()`,
`playlists()` and `favourites()`.

4. COMMANDS					*gtm.nvim-commands*

Playback:~
  :Gtm play              Toggle play/pause.
  :Gtm next              Skip to next track.
  :Gtm prev              Skip to previous track.
  :Gtm stop              Stop playback.
  :Gtm volup             Increase volume by 5%.
  :Gtm voldown           Decrease volume by 5%.
  :Gtm mute              Toggle mute.
  :Gtm seek {secs}       Seek to position in seconds.
  :Gtm shuffle           Toggle shuffle.
  :Gtm repeat            Cycle repeat: off -> one -> all -> off.
  :Gtm repeat {mode}     Set repeat mode: off|one|all.

Status:~
  :Gtm status            Notify what is playing right now.

Every message the plugin shows carries the same marker, `[gtm] 📻️ `, so a gtm
notification is recognisable in a busy message list. It is a constant: there is
no option for it.

Browsing:~
  :Gtm queue [action]    Browse the queue; action is remove or clear.
  :Gtm spotify [query]   Search Spotify; only tracks are listed.
  :Gtm spotify-playlists Browse synced Spotify playlists.
  :Gtm radio [arg]       Top stations, a search, tags or countries.
  :Gtm search [query]    Search the local library.
  :Gtm playlists         Browse local playlists.
  :Gtm favourites        Browse favourites.

Reactive theming: >
  :Gtm theme             Print the active palette as hex values.
  :Gtm theme reset       Clear the tint and restore the previous colors.
<

5. REACTIVE THEMING					*gtm.nvim-theme*

On by default. The editor takes on the colours of the album currently playing.
gtmd extracts the palette from the cover art and broadcasts a resolved role set;
this plugin never decodes an image. It maps roles onto highlight groups, which
keeps it, the gtm TUI, and any other client in agreement.

  - Backgrounds are your colorscheme's own colours washed toward the album accent
    by `theme.intensity` (default 0.34), so the editor stays your theme rather
    than being replaced by a fixed dark surface. Set it to 0 to leave
    backgrounds alone while accents and syntax still follow the album.
  - The tint is kept while playback is paused and dropped only when playback
    stops or the track ends.
  - Semantic groups (Error, Warning, Diff, Spell, Todo, diagnostics, gitSigns)
    keep their colorscheme colours.
  - Changing colorscheme mid-track re-picks light or dark and re-tints.
  - A track change re-tints live. If the pulse stream drops, it reconnects on
    its own, and the tint is re-asserted on the periodic resync.
  - A track with no cover art never tints.
  - `:Gtm theme reset` restores every group to exactly its prior value.

Turn it off with `theme = { reactive = false }`. Tune the background wash with
`theme.intensity`, and add your own groups to the tint with `theme.extra_groups`.

The plugin resolves no roles itself. Against a gtmd that predates role sets the
editor stays untinted; `:checkhealth gtm` reports that rather than leaving you
to wonder.

6. LUA API						*gtm.nvim-api*

Playback~
  require("gtm").play_pause()      Toggle play/pause.
  require("gtm").next()            Next track.
  require("gtm").prev()            Previous track.
  require("gtm").stop()            Stop.
  require("gtm").mute()            Toggle mute.
  require("gtm").shuffle()         Toggle shuffle.
  require("gtm").cycle_repeat(m)   Set repeat: "off"|"one"|"all". No argument
                                  cycles through them.
  require("gtm").seek(secs)        Seek to a position in seconds.
  require("gtm").set_volume(d)     Nudge the volume by a delta.

Statusline~
  require("gtm").statusline()        Render the enabled items.
  require("gtm").lualine_component()  lualine component table.

Browsing~
  require("gtm").queue(action)        Browse the queue; action is "remove" or
                                      "clear" (optional).
  require("gtm").spotify(query)       Search Spotify; prompts when query is nil.
  require("gtm").spotify_playlists()  Browse synced Spotify playlists.
  require("gtm").radio(arg)           Top stations, a query, "tags" or "countries".
  require("gtm").search(query)        Search the local library; prompts when nil.
  require("gtm").playlists()          Browse local playlists.
  require("gtm").favourites()         Browse favourites.

Note: `repeat` is a Lua keyword, so the public entry point is
`cycle_repeat()`, not `repeat()`.

7. CONFIGURATION					*gtm.nvim-config*

Defaults: >
  {
    resync_interval = 30000, -- ms between get_status_lite resyncs
    statusline = {
      source = true, state = true,
      artist = false, title = false, album = false, progress = false,
      time = false, volume = false, repeat = false, shuffle = false,
    },
    theme = { reactive = true, intensity = 0.34, extra_groups = {} },
    keymaps = {},
  }
<
`socket_path` overrides the socket search order, which otherwise matches gtmd's
own: `$XDG_RUNTIME_DIR/gtm/gtmd.sock`, `/tmp/gtm-$USER/gtm/gtmd.sock`,
`$TMPDIR/gtm/gtmd.sock`, then `~/.gtm/gtm/gtmd.sock`. The plugin does not start
the daemon for you.

A `vim.ui.select` provider (fzf-lua, Telescope, snacks) is optional: without one
the pickers fall back to the stock numbered list.

8. HEALTH						*gtm.nvim-health*

>
  :checkhealth gtm
<
Reports the Neovim version, whether `gtmd` is on `$PATH`, both socket paths and
whether they are connected, the age of the last pulse heartbeat and of the last
status snapshot, and whether a palette has arrived. Start here when nothing is
happening.
