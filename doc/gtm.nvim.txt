1. SETUP                                                      *gtm.nvim-setup*

Requires GTM daemon (gtmd) running on the same machine.

With lazy.nvim: >
  { "prjctimg/gtm.nvim", opts = {} }
<
Manual: >
  require("gtm").setup({ statusline_format = "compact" })
<
==============================================================================
2. COMMANDS                                                *gtm.nvim-commands*

Playback:~
  :Gtm float          Toggle the GTM floating window.
  :Gtm play           Toggle play/pause.
  :Gtm next           Skip to next track.
  :Gtm prev           Skip to previous track.
  :Gtm stop           Stop playback.
  :Gtm volup          Increase volume by 5%.
  :Gtm voldown        Decrease volume by 5%.
  :Gtm shuffle        Toggle shuffle.
  :Gtm repeat {mode}  Set repeat mode: off|one|all.
  :Gtm mute           Toggle mute.
  :Gtm seek {secs}    Seek to position in seconds.
  :Gtm status         Show current track in a notification.
  :Gtm theme {status|reset}
                      Print the active reactive-theme palette hexes, or
                      clear the tint.
  :Gtm disconnect     Disconnect from the daemon socket.

Library:~
  :Gtm library        Open the library track list.
  :Gtm playlists      Open the playlist list.
  :Gtm scan {path}    Scan a directory and add tracks to library.

Library motions (inside library buffer):~
  j / <Down>          Move cursor down
  k / <Up>            Move cursor up
  gg                  Jump to first track
  G                   Jump to last track
  <CR>                Play selected track
  d                   Delete track from library
  a                   Add track to queue
  F                   Toggle favourite on selected track
  t                   Switch to playlist view
  /                   Filter/search library
  q / <Esc>           Close library window

Equalizer:~
  :Gtm eq on          Enable equalizer.
  :Gtm eq off         Disable equalizer.
  :Gtm eq {preset}    Set EQ preset: flat|pop|rock|jazz|classical|bass|
                      vocal|electronic|hip_hop|latin|acoustic|podcast|
                      dance|headphones|speaker

YouTube:~
  :Gtm yt             Search YouTube (prompts for query).
  :Gtm yt {query}     Search YouTube for query.
  :Gtm yt download    Download a track (prompts for URL/search).
  :Gtm yt download {url}  Download from URL or search query.

==============================================================================
3. LIBRARY                                                  *gtm.nvim-library*

The library window shows all tracks in the GTM daemon's library.
Use |j|/|k| to navigate, |<CR>| to play, |d| to delete, |a| to add
to queue, |F| to toggle favourite, |/| to filter, |t| for playlists.

Library commands connect to the daemon via IPC and query the track
database. Use |:Gtm scan| to add new directories.

==============================================================================
4. EQUALIZER                                              *gtm.nvim-equalizer*

15-band ISO 1/3-octave EQ with presets:
  flat, pop, rock, jazz, classical, bass, vocal, electronic,
  hip_hop, latin, acoustic, podcast, dance, headphones, speaker

Gains are capped at +/-5 dB. Q value: 1.414 (1/3-octave bandwidth).

Note: The EQ DSP is not yet implemented in the daemon — only the
preset switching and IPC plumbing are functional.

==============================================================================
5. YOUTUBE                                                  *gtm.nvim-youtube*

Search YouTube via yt-dlp and download audio tracks directly.

Flow:
  1. :Gtm yt {query} starts a search
  2. Results appear in a floating picker buffer
  3. Press <CR> on a result to download it
  4. The track is downloaded as MP3 to ~/.local/share/gtm/audio/
  5. Library is automatically rescanned after download

Direct download: >
  :Gtm yt download https://youtube.com/watch?v=...
<

6. STATUSLINE                                          *gtm.nvim-statusline*

Two formats are available:
  - "compact": `Artist - Title [▶] vol:80% ━━━━━━`
  - "detailed": `▶ Artist / Title (Album) [01:23/04:56] vol:80%`

lualine integration: >
  require("lualine").setup({
    sections = {
      lualine_x = { require("gtm").lualine_component() },
    },
  })
<

7. FLOAT                                                    *gtm.nvim-float*

Native floating-window playback UI. Layout:

  ┌─────────────────────────────────┬─────────────────────────────────┐
  │             cover art           │  ▶ Title                        │
  │        (image.nvim, left panel) │     Artist                     │
  │                                 │     Album                      │
  │                                 │   [01:23/04:56] ━━━━━━━━━━━━   │
  └─────────────────────────────────┴─────────────────────────────────┘

The cover panel is rendered with |3rd/image.nvim| when installed; without
it the artwork area collapses and a ♪ placeholder is drawn. The text panel
uses per-line |nvim_buf_add_highlight| records (`GtmIcon`, `GtmTitle`,
`GtmArtist`, `GtmAlbum`, `GtmTime`, `GtmBar`, `GtmBarEmpty`) plus the
`NormalFloat`/`FloatBorder`/`FloatTitle`/`FloatFooter` groups, so the whole
float honors the reactive theme (|gtm.nvim-theme|) automatically.

Toggle with |:Gtm float| or the mapped key; resize with |VimResized|.

==============================================================================
8. COVER ART                                               *gtm.nvim-cover*

Artwork resolution is daemon-first: the plugin sends |get_cover_art| on
the command socket, decodes the base64 payload, sniffs its file signature
(JPEG/PNG/WebP/...) and caches it under `stdpath("cache")/gtm/cover`
keyed by track hash. `fetch()` resolution order:

  1. plugin cache (hash-derived key)
  2. daemon `get_cover_art` payload
  3. `track.cover_path` / `cover.jpg`-style sidecars next to the audio file

The cache is deliberately separate from the daemon's own cover cache; the
plugin's `cleanup()` never touches the daemon's directory.

==============================================================================
9. REACTIVE THEMING                                         *gtm.nvim-theme*

Disable by default; enable with `theme.reactive = true`.

When a track starts playing, the current artwork is downscaled to 24×24
raw RGB (via ffmpeg, falling back to ImageMagick) and quantized into a
3-color palette (dominant, secondary, tertiary). The palette drives the
float's global highlight groups:

  - the float background gets an ambient wash of the dominant color at
    `theme.intensity` (clamped 0..0.5);
  - text/border accents take the palette hues through a
    contrast-preserving adjustment;
  - dim foreground colors are re-tuned for readability against the tint.

The tint is kept while playback is paused and restored exactly — per-group
`nvim_get_hl {link=true}` snapshots taken at setup — on stop, track
change, colorscheme swap (`ColorScheme` rebundle), or plugin close
(`VimLeavePre`). |:Gtm theme status| prints the active palette hexes;
|:Gtm theme reset| clears the tint immediately.

`theme.extra_groups` accepts additional highlight names to tint alongside
the float groups.

10. CONFIG                                                 *gtm.nvim-config*

>lua
  require("gtm").setup({
    socket_path = nil,              -- auto-detect
    statusline_format = "compact",  -- "compact" | "detailed"
    resync_interval = 30000,        -- get_status_lite resync (ms)
    float = {
      width = 0.8,
      height = 0.8,
      border = "rounded",
      cover_art = true,             -- requires 3rd/image.nvim
    },
    theme = {
      reactive = false,             -- tint float from album art
      intensity = 0.2,              -- background wash strength (0..0.5)
      extra_groups = {},            -- extra highlights to tint
    },
    keymaps = {
      play_pause = "<leader>gp",
      next = "<leader>gn",
      prev = "<leader>gN",
      volume_up = "<leader>g>",
      volume_down = "<leader>g<",
      float = "<leader>gf",
      stop = "<leader>gS",
    },
  })
<
